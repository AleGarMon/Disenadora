# Alejandra García — Portfolio

Sitio estático bilingüe preparado para GitHub Pages.

## Versión
Esta versión incorpora la paleta Inked, textos originales recuperados del Canva, descripciones de Branding, reordenamiento de Motion y pie legal global.

## Publicar
Sube el contenido de esta carpeta a la raíz de la rama `main` y activa GitHub Pages desde **Settings → Pages → Deploy from a branch → main → /(root)**.
